**2D 지도 공식은 평면 좌표계에서 두 점 사이의 거리를 계산하는 유클리드 거리 공식이고, 3D 지도 공식은 여기에 z축을 추가하여 공간상의 거리를 계산합니다. 지도 좌표(위도·경도)는 구면 좌표이므로 Haversine 공식 같은 구면 거리 계산을 사용합니다.**  [tools.devcomma.com](https://tools.devcomma.com/calculators/coordinate-distance)  [science-gallery-park.tistory.com](https://science-gallery-park.tistory.com/entry/%EC%A7%81%EA%B0%81%EC%A2%8C%ED%91%9C%EA%B3%84-%EA%B3%B5%EC%8B%9D-%EC%B4%9D%EC%A0%95%EB%A6%AC-%EB%91%90-%EC%A0%90-%EC%82%AC%EC%9D%B4-%EA%B1%B0%EB%A6%AC-%EC%A4%91%EC%A0%90-%EC%A7%81%EC%84%A0-%EB%B0%A9%EC%A0%95%EC%8B%9D-%EC%89%BD%EA%B2%8C-%EB%B0%B0%EC%9A%B0%EA%B8%B0?category=1252887)

## 📐 2D 지도 공식 (평면 좌표계)
- **좌표 표현**: 점 A \((x_1, y_1)\), 점 B \((x_2, y_2)\)
- **거리 공식**:  
  \[
  d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
  \]
- **활용 분야**:
  - 그래프, 도면, CAD 설계
  - 데이터 분석 (산점도, 클러스터링)
  - 게임 개발 (캐릭터 간 거리 계산)  [tools.devcomma.com](https://tools.devcomma.com/calculators/coordinate-distance)

## 📊 3D 지도 공식 (공간 좌표계)
- **좌표 표현**: 점 A \((x_1, y_1, z_1)\), 점 B \((x_2, y_2, z_2)\)
- **거리 공식**:  
  \[
  d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}
  \]
- **활용 분야**:
  - 3D 모델링, 건축 설계
  - 센서 데이터 (LiDAR, 포인트 클라우드)
  - 물리 시뮬레이션, GIS 3D 지도 제작  [tools.devcomma.com](https://tools.devcomma.com/calculators/coordinate-distance)  [kimhongsi.tistory.com](https://kimhongsi.tistory.com/entry/%EB%AA%A8%EB%B9%8C%EB%A6%AC%ED%8B%B0-%EB%94%94%EC%A7%80%ED%84%B8-3D-%EC%A7%80%EB%8F%84-%EC%A0%9C%EC%9E%91-%EA%B3%BC%EC%A0%95-2D%EC%A7%80%EB%8F%84%EC%99%80%EC%9D%98-%EC%B0%A8%EC%9D%B4-%EC%A0%95%EB%A6%AC)

## 🌍 지도 좌표 (위도·경도) 공식
- **문제점**: 지구는 구형이므로 단순한 2D/3D 직선 거리 계산은 오차 발생
- **Haversine 공식**: 두 위도·경도 좌표 간의 대권거리(구면 최단거리)를 근사
  \[
  d = 2r \cdot \arcsin\left(\sqrt{\sin^2\left(\frac{\Delta \varphi}{2}\right) + \cos(\varphi_1)\cos(\varphi_2)\sin^2\left(\frac{\Delta \lambda}{2}\right)}\right)
  \]
  - \(\varphi\): 위도, \(\lambda\): 경도, \(r\): 지구 반지름
- **정밀 계산**: WGS84 타원체 모델 기반 Vincenty 공식 사용 가능  [tools.devcomma.com](https://tools.devcomma.com/calculators/coordinate-distance)
