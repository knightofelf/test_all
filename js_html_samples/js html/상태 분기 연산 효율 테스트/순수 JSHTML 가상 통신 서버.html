JS / HTML 단일 파일 통신 시스템

※ Node.js나 서버 설치 없이 브라우저 단독으로 동작합니다.

1. 외부 무료 API 서버와 실제 통신 (Fetch API)

인터넷이 연결되어 있으면 외부 테스트 서버와 실시간으로 데이터를 주고받습니다.

결과가 여기 표시됩니다.

2. 브라우저 내부 가상 서버 통신 (Service Worker)

브라우저 내부에 가상 주소(/virtual-api/data)를 만들어 통신을 흉내 냅니다.

결과가 여기 표시됩니다.

3. 로컬 데이터베이스 통신 (LocalStorage)

새로고침을 해도 데이터가 브라우저에 안전하게 영구 저장됩니다.

결과가 여기 표시됩니다.
