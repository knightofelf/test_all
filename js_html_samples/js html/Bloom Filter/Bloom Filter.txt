
//
Bloom Filter는 메모리를 아주 적게 쓰면서도 빠르게 “존재 여부”를 판단할 수 있는 확률적 자료구조입니다.
단점은 false positive(존재하지 않는데 있다고 판단할 수 있음)가 생길 수 있지만, false negative는 없습니다.


//
이 두 기능은 오타 교정이나 유사 단어 탐지에 자주 쓰입니다.

N-Gram: 단어를 일정 길이의 문자 조각으로 나눠서 비교합니다.

Delete 버전: 한 글자를 삭제한 모든 조합을 저장해 오타를 빠르게 탐지합니다.



🧠 설명
N-Gram 버튼: 입력된 문자열을 3글자씩 나누어 Bloom Filter에 추가합니다.
→ "apple" → "app", "ppl", "ple"

Delete 버전 버튼: 한 글자를 제거한 모든 조합을 추가합니다.
→ "apple" → "pple", "aple", "appe", "appl"


//
🧠 특징
비트 배열 크기 2,000,000 → 100만 개 이상 데이터도 안정적으로 처리 가능.

해시 함수 7개 → 충돌률을 줄이고 false positive 확률을 낮춤.

N-Gram 버튼 → 문자열을 3글자 단위로 나눠 저장, 유사 검색에 유리.

Delete 버전 버튼 → 한 글자 빠진 오타도 탐지 가능.

대량 삽입 버튼 → 100만 개 데이터를 자동으로 Bloom Filter에 추가.
