좋습니다! 이제 실제로 **랜덤 바이트 값**을 만들어서 16×16 이미지의 원본 → 대칭 → 역함수 과정을 보여드릴게요.  

각 줄은 16픽셀 → 2바이트로 표현되므로, 총 16줄 × 2바이트 = **32바이트 배열**입니다.

### 🔄 대칭 (Mirror)
좌우 반전은 바이트 순서를 뒤집는 방식입니다.  
예: `0x3A 0xF7` → `0xF7 0x3A`

```
Row 1: 0xF7 0x3A
Row 2: 0x0C 0x91
Row 3: 0xA2 0x5E
Row 4: 0x10 0xFF
Row 5: 0x44 0x7B
Row 6: 0x81 0xC9
Row 7: 0xD3 0x22
Row 8: 0xB0 0x6F
Row 9: 0x9E 0x14
Row 10: 0x77 0x88
Row 11: 0x02 0xAB
Row 12: 0xC1 0xD4
Row 13: 0xFE 0x39
Row 14: 0x5A 0x60
Row 15: 0x11 0xE3
Row 16: 0x9C 0x4D
```

---

### ↔ 역함수 (Inverse)
좌우 반전은 자기 자신이 역함수입니다.  
즉, 대칭을 한 번 더 하면 원본이 복원됩니다:

```
Row 1: 0x3A 0xF7
Row 2: 0x91 0x0C
Row 3: 0x5E 0xA2
Row 4: 0xFF 0x10
Row 5: 0x7B 0x44
Row 6: 0xC9 0x81
Row 7: 0x22 0xD3
Row 8: 0x6F 0xB0
Row 9: 0x14 0x9E
Row 10: 0x88 0x77
Row 11: 0xAB 0x02
Row 12: 0xD4 0xC1
Row 13: 0x39 0xFE
Row 14: 0x60 0x5A
Row 15: 0xE3 0x11
Row 16: 0x4D 0x9C
```

---

✅ 이렇게 랜덤 바이트 배열을 만들어도, **대칭 변환은 자기 자신이 역함수**라는 성질을 그대로 확인할 수 있습니다.
