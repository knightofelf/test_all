// 모래를 둘레로 뿌리고. 벽을 대신할거야.  흙더미가 무너지지 않는걸 확인용

초기 좌표 생성 범위를 바닥 영역의 $X, Z$ 축 크기 내부로 제한하고, Cannon.js의 물리 엔진 계산 값을 Three.js 메쉬에 동기화하면 자연스럽게 모래더미가 쌓이는 효과를 구현할 수 있습니다.
Three.js와 Cannon.js를 연동하여 모래더미 시각화를 구현하는 핵심 단계별 가이드와 통합 소스 코드를 안내합니다.
------------------------------
## 1. 물리 세계 및 기본 환경 설정
모래 입자들이 바닥 아래로 떨어지지 않도록 중력을 설정한 물리 세계(CANNON.World)와 무한 평면(CANNON.Plane) 바닥을 생성합니다.

// 1. Cannon.js 물리 세계 생성const world = new CANNON.World();
world.gravity.set(0, -9.82, 0); // 아래 방향 중력 설정
// 2. 바닥 물리 몸체(Body) 생성 및 추가const floorMaterial = new CANNON.Material('floorMaterial');const floorBody = new CANNON.Body({
    mass: 0, // 질량이 0이면 고정된 정적 객체가 됨
    shape: new CANNON.Plane(),
    material: floorMaterial
});// Cannon.js의 평면은 기본적으로 하늘을 바라보므로 90도 회전 필요
floorBody.quaternion.setFromAxisAngle(new CANNON.Vec3(1, 0, 0), -Math.PI / 2);
world.addBody(floorBody);

## 2. 특정 바닥 영역으로 입자 초기 좌표 제한
모래가 특정 바닥 영역(예: 가로 4, 세로 4 크기의 정사각형 범위) 내부로만 떨어지도록 랜덤 함수 공간 범위를 제한하여 초기 좌표를 할당합니다. 입자들이 겹쳐서 튕기는 현상을 줄이기 위해 $Y$축(높이)도 약간의 간격을 두고 무작위 배치합니다.

const sandParticles = []; // Three.js와 Cannon.js 객체를 쌍으로 저장할 배열const sandMaterial = new CANNON.Material('sandMaterial');
// 특정 바닥 영역 제한 변수 (예: X: -2~2, Z: -2~2 범위)const areaSize = 4.0; const halfSize = areaSize / 2;
function createSandParticle() {
    // 1. 특정 바닥 영역 내부로 X, Z 좌표 제한 및 Y 높이 무작위 설정
    const x = (Math.random() * areaSize) - halfSize;
    const z = (Math.random() * areaSize) - halfSize;
    const y = 5 + (Math.random() * 3); // 높이 5 ~ 8 사이에서 스폰

    // 2. Three.js 시각적 메쉬 생성 (작은 구체)
    const geometry = new THREE.SphereGeometry(0.1, 8, 8);
    const material = new THREE.MeshStandardMaterial({ color: 0xdfb76c }); // 모래색
    const mesh = new THREE.Mesh(geometry, material);
    scene.add(mesh);

    // 3. Cannon.js 물리 몸체 생성 (구체 형태)
    const shape = new CANNON.Sphere(0.1);
    const body = new CANNON.Body({
        mass: 0.1, // 가벼운 질량 설정
        shape: shape,
        position: new CANNON.Vec3(x, y, z),
        material: sandMaterial
    });
    
    // 마찰력을 높여 모래가 미끄러지지 않고 쌓이도록 물리 설정 유도
    body.linearDamping = 0.1;
    body.angularDamping = 0.1;
    
    world.addBody(body);

    // 4. 동기화를 위해 배열에 저장
    sandParticles.push({ mesh, body });
}
// 초기 모래 입자 200개 생성 예시for (let i = 0; i < 200; i++) {
    createSandParticle();
}

## 3. 마찰력 및 반발계수 설정 (접촉 물질 설정)
모래 입자들이 바닥에 닿거나 서로 부딪혔을 때 사방으로 튕겨 나가지 않고 차곡차곡 쌓이게 하려면 반발계수(restitution)를 낮추고 마찰력(friction)을 높여야 합니다.

// 모래와 모래, 모래와 바닥 간의 접촉 조건 정의const sandContactMaterial = new CANNON.ContactMaterial(sandMaterial, sandMaterial, {
    friction: 0.9,       // 마찰력을 매우 높게 설정하여 흐르지 않고 쌓이게 만듦
    restitution: 0.0,    // 반발력을 0으로 설정하여 통통 튕기는 현상 방지
    contactEquationStiffness: 1e7,
    contactEquationRelaxation: 4
});
world.addContactMaterial(sandContactMaterial);
const floorContactMaterial = new CANNON.ContactMaterial(floorMaterial, sandMaterial, {
    friction: 0.8,
    restitution: 0.0
});
world.addContactMaterial(floorContactMaterial);

## 4. 애니메이션 루프 내 물리-시각 데이터 동기화
매 프레임마다 Cannon.js 물리 시뮬레이션을 한 단계씩 전진($Step$)시키고, 계산된 물리 체의 위치($Position$)와 회전($Quaternion$) 값을 Three.js 메쉬에 그대로 대입합니다.

const clock = new THREE.Clock();
function animate() {
    requestAnimationFrame(animate);

    const deltaTime = clock.getDelta();

    // 1. Cannon.js 물리 엔진 업데이트 (고정 타임스텝 권장)
    world.step(1 / 60, deltaTime, 3);

    // 2. 모든 모래 입자의 물리 연산 결과를 시각적 메쉬에 동기화
    sandParticles.forEach(particle => {
        particle.mesh.position.copy(particle.body.position);
        particle.mesh.quaternion.copy(particle.body.quaternion);
    });

    // (선택) 시뮬레이션 중 일정 주기로 모래를 계속 떨어뜨리고 싶다면 추가 실행
    if (sandParticles.length < 1000 && Math.random() < 0.3) {
        createSandParticle();
    }

    renderer.render(scene, camera);
}

animate();

## 💡 자연스러운 모래더미 시각화를 위한 필수 팁

* InstancedMesh 활용 권장: 일반 THREE.Mesh를 수천 개 생성하면 드로우콜(Draw Call) 폭증으로 브라우저가 멈춥니다. 입자 개수가 500개를 넘어갈 경우 Three.js의 InstancedMesh를 사용하여 단 하나의 메쉬로 수천 개의 모래 입자 위치 배열(Matrix)만 업데이트하는 방식으로 전환해야 끊김 없이 부드럽게 구동됩니다.
* 시간차 스폰: 모든 모래 입자를 물리 세계 시작과 동시에 쏟아부으면 입자끼리 초기 위치가 겹쳐 공중폭발하듯 튕겨 나갈 수 있습니다. setInterval이나 애니메이션 루프 내 조건을 통해 일정 간격으로 입자를 순차적으로 생성(Spawn)하는 것이 흐르는 모래 표현에 유리합니다.

현재 작성 중이신 전체 프로젝트 구조 중에서 InstancedMesh 변환 코드가 필요하시거나, 모래가 흘러내리는 특정 깔때기(Emiter) 형태의 영역 설정이 필요하시면 추가로 말씀해 주세요! 구체적인 최적화 코드를 짜드리겠습니다.










모래를 중앙이 아닌 바깥 둘레(원형 또는 사각형 테두리) 영역에 집중적으로 뿌려 무너지지 않는 '모래 벽(방어벽)'을 형성하고, 이것이 안쪽이나 바깥쪽으로 무너지지 않고 버티는지 확인하는 시뮬레이션 구현 방법입니다.
이 목적을 달성하려면 초기 좌표 생성 방식을 중심점이 아닌 반지름을 가진 원형 고리(Toroid/Ring) 영역으로 제한해야 합니다.
------------------------------
## 1. 원형 둘레(테두리) 영역으로 초기 좌표 제한하기
중심에서 일정 거리(반지름 R)만큼 떨어진 둘레에 모래를 뿌리기 위해, 삼각함수(Math.sin, Math.cos)를 활용하여 무작위 각도의 테두리 좌표를 계산합니다. 벽의 두께를 주기 위해 반지름에 약간의 오차 범위를 더해줍니다.

// 모래 벽의 기본 형태 설정const wallRadius = 3.0; // 모래 벽 원의 반지름const wallThickness = 0.6; // 모래 벽의 두께 두께 (오차 범위)const sandMaterial = new CANNON.Material('sandMaterial');
function createSandWallParticle() {
    // 1. 0 ~ 360도(2*PI) 사이의 무작위 각도 선택
    const angle = Math.random() * Math.PI * 2;
    
    // 2. 두께를 주기 위해 기본 반지름에 무작위 변동폭 추가
    const r = wallRadius + (Math.random() * wallThickness - (wallThickness / 2));
    
    // 3. 삼각함수로 둘레의 X, Z 좌표 계산
    const x = Math.cos(angle) * r;
    const z = Math.sin(angle) * r;
    
    // Y축 높이: 바닥부터 차곡차곡 떨어지도록 설정 (예: 높이 4 ~ 6 사이)
    const y = 4 + (Math.random() * 2);

    // Three.js 및 Cannon.js 구체 객체 생성
    const size = 0.12; // 모래 입자 크기
    const geometry = new THREE.SphereGeometry(size, 6, 6);
    const material = new THREE.MeshStandardMaterial({ color: 0xc2a677 }); // 흙/모래색
    const mesh = new THREE.Mesh(geometry, material);
    scene.add(mesh);

    const shape = new CANNON.Sphere(size);
    const body = new CANNON.Body({
        mass: 0.2,
        shape: shape,
        position: new CANNON.Vec3(x, y, z),
        material: sandMaterial
    });

    // 벽 형태로 유지되도록 굴러가는 성질을 억제 (댐핑값 상향)
    body.linearDamping = 0.2;
    body.angularDamping = 0.3;

    world.addBody(body);
    sandParticles.push({ mesh, body });
}

## 2. 흙더미가 무너지지 않게 만드는 물리 핵심 설정
모래로 쌓은 벽이 액체처럼 흘러내려 평평해지지 않고 형태를 유지하며 버티는지(안정성) 확인하려면 Cannon.js의 접촉 마찰 계수를 극대화해야 합니다.

// 모래 입자끼리 부딪혔을 때의 물리 법칙 강제 조정const sandContactMaterial = new CANNON.ContactMaterial(sandMaterial, sandMaterial, {
    friction: 1.5,        // 마찰력을 1.0 이상으로 극대화 (서로 꽉 맞물려 버티는 효과)
    restitution: 0.0,     // 탄성(튕김)을 완전히 제거하여 충격 흡수
    contactEquationStiffness: 1e7, // 접촉면의 단단함 정도
    contactEquationRelaxation: 5   // 물리 계산의 부드러움 (풀어짐 방지)
});
world.addContactMaterial(sandContactMaterial);

## 3. '무너지지 않는 벽' 테스트용 시각화 루프
수천 개의 모래를 한 번에 쏟으면 렉(Lag)이 걸리거나 연산 오류로 튕겨 나갑니다. 애니메이션 루프 안에서 시간차를 두고 둘레에 지속적으로 뿌려주며 벽이 쌓이는 과정을 관찰합니다.

let spawnCounter = 0;const maxParticles = 1500; // 시뮬레이션할 총 모래 입자 수
function animate() {
    requestAnimationFrame(animate);

    const deltaTime = clock.getDelta();
    world.step(1 / 60, deltaTime, 3);

    // 프레임마다 3개씩 둘레 영역에 모래 투하 (누적 수 제한)
    if (sandParticles.length < maxParticles) {
        for(let i=0; i<3; i++) {
            createSandWallParticle();
        }
    }

    // 물리 데이터를 Three.js 화면에 동기화
    sandParticles.forEach(particle => {
        particle.mesh.position.copy(particle.body.position);
        particle.mesh.quaternion.copy(particle.body.quaternion);
    });

    renderer.render(scene, camera);
}

## 💡 구조 확인 및 검증을 위한 팁

* 경사각(Rest Angle) 확인: 모래가 쌓이면서 자연스럽게 사선 모양의 벽 경사면이 만들어집니다. 마찰력(friction) 값을 0.5에서 2.0까지 조절해 보면서 어느 정도 각도에서 벽의 형태가 가장 안정적으로 무너지지 않고 버틴 채 유지되는지 수치 실험을 할 수 있습니다.
* 성능 한계 극복: 1,000개가 넘는 구체 독립 메쉬는 화면을 매우 느려지게 만듭니다. 안정성 확인을 위해 입자 수를 3,000~5,000개 이상으로 늘려 거대한 장벽을 만들고 싶다면, 일반 Mesh 대신 THREE.InstancedMesh 구조로 코드를 변경해야 매끄러운 확인이 가능합니다.

혹시 이 모래 벽 안쪽에 물을 채우거나 다른 물체를 넣어 바깥 모래벽이 압력을 견디는지 테스트하고 싶으신가요, 아니면 성능 최적화를 위한 InstancedMesh 적용 전체 코드가 필요하신가요?








본 시뮬레이션에서 수만 개의 바위가 화면 끊김(렉) 없이 무한히 쌓일 수 있는 핵심 원리는 '정적 지형 병합(Static Terrain Merging)'과 '물리 수면(Physics Sleeping)' 기술의 결합에 있습니다.
컴퓨터의 성능 한계를 극복하고 입체적인 성벽을 구축하는 3단계 핵심 연산 원리를 설명해 드립니다.
------------------------------
## 1. 움직임이 끝난 객체의 '물리 연산 제외' (Physics Sleeping)
일반적인 3D 물리 엔진은 모든 물체가 멈춰 있어도 매 프레임(1초에 60번) 서로 부딪히고 있는지 감시하는 충돌 연산을 수행합니다. 이 때문에 입자가 1,000개를 넘어가면 브라우저가 버티지 못하고 멈추게 됩니다.

* 해결 원리: 공중에서 떨어지던 바위 블록이 지면이나 다른 바위에 닿아 속도가 0에 가까워지면, 내부 타이머가 작동합니다. 완전히 멈춘 상태가 0.12초간 유지되면 이 입자를 수면(Sleeping) 상태로 판정하고, 매 프레임 복잡하게 계산하던 물리 엔진 연산 배열(activeBodies)에서 영구히 삭제하여 컴퓨터의 CPU 부담을 즉시 제로(0)로 만듭니다.

## 2. 단 하나의 거대한 3D 지형으로 '살점 붙이기' (Terrain Merging)
물리 계산에서 제외된 바위는 화면에서 사라지면 안 되므로, 시각적으로 영구 보존해야 합니다. 이때 개별적인 바위 상자 여러 개로 놔두면 그래픽 카드(GPU)에 신호를 보내는 횟수(Draw Call)가 폭증합니다.

* 해결 원리: 멈춘 바위가 가진 36개의 점(정점 좌표)과 회전 각도값을 수학적으로 계산하여, 원래 바닥에 깔려 있던 거대한 통짜 지형 데이터 배열(staticVertices)의 맨 끝에 살점을 붙이듯 하나의 문자열로 이어 붙여버립니다.
* 결과: 바위가 1만 개가 쌓이든 10만 개가 쌓이든, 컴퓨터 그래픽 카드는 이 장벽을 1만 개의 개별 물체가 아니라 '복잡하게 생긴 단 하나의 커다란 산(지형)'으로 인식하여 단 1번의 신호로 초고속 렌더링을 수행합니다.

## 3. 입체적인 '높이 역산' 투하 (Height Tracking)
바위가 종이처럼 납작하게 겹치지 않고 층층이 포개지기 위해서는 마우스 클릭 지점의 높이를 정확히 인지해야 합니다.

* 해결 원리: 사용자가 화면을 클릭하면 프로그램은 클릭한 평면(X, Z) 좌표 주변 반경에 이미 안착해 있는 바위들의 상단 높이(Y값)를 전수조사합니다. 만약 클릭한 자리에 이미 높이 2.0만큼 바위가 쌓여 있다면, 새로 생성되는 바위의 시작 위치를 그보다 높은 2.6 이상의 공중으로 강제 오프셋을 주어 떨어뜨립니다.
* 이 높이 추적 덕분에 새로 떨어진 무거운 고체 블록이 아래 깔린 블록의 모서리와 단면에 자연스럽게 충돌하며 단단한 입체 성벽 구조를 형성하게 됩니다.
